# CNC 雙程式路線模擬器

目前版本：v1.12.0。公開版使用不對應任何真實工件的合成 A／B 範例程式，支援 FANUC G52 局部座標偏移；重構只採用已完成的慢速加工線，並將 M31～M34 各加工面依轉盤中心反旋至零度面，從中心兩側最大加工半徑推算物件寬、高與長度。缺少副程式或刀補時，尺寸只代表目前可解析加工面。

繁體中文、離線優先的 Fanuc 類 3+1 軸 CNC 程式設計與教學預檢工具。

> 本專案為實驗性軟體。公開版不含真實生產 NC 程式、機台專用參數、客戶資料或開發備份。

## v1.12.0 更新內容

- 新增可設定的 M31～M34 四面轉盤、零度面與旋轉方向。
- 新增 G52 局部座標偏移的解析、機械座標換算與測試。
- 將已完成的慢速加工線反旋重構為 3D 工件外殼。
- 依轉盤中心與可解析加工面推算寬、高與長度。
- 改善轉盤播放、相機自動取景、即時狀態與 Three.js 資源釋放。
- 新增重構與解析回歸測試；公開預設改用合成範例。

完整版本紀錄請見 [CHANGELOG.md](CHANGELOG.md)。

## 使用

```powershell
npm install
npm run dev
```

正式建置：`npm run build`；測試：`npm test`。

## 桌面一鍵開啟

執行 `建立桌面捷徑.ps1` 後，桌面會出現「CNC 雙程式路線模擬器」捷徑。點擊捷徑會在背景啟動本機伺服器並開啟瀏覽器；若伺服器已啟動，只會開啟網頁，不會重複啟動。

## 能力與限制

- A/B 程式編輯、匯入、下載、同步差異統計與雙色 3D 路徑。
- A/B 各自提供文字搜尋；輸入即定位，Enter／Shift+Enter 或上下按鈕可在命中內容間循環跳轉。
- MACRO 分頁索引 8000/9000 系列巨集本體與 G65 呼叫；刀庫分頁提供可編輯口袋映射、A/B 刀號使用統計及主軸／待命刀追蹤。
- 模擬工具列可即時切換 `/` 區段跳脫；開啟時略過斜線單節，關閉時執行。
- 支援常用 G0/G1/G2/G3、G17/18/19、G20/21、G54–59、G80、G81～G84、G90/91、X/Y/Z/W 與基本 Fanuc 變數算式；其他固定循環在缺少機台資料時回報未展開，不宣稱完整模擬。
- 機台設定可輸入 G54～G59 工件原點、G43 H 刀長補正及自設變數；支援 FANUC 0M 常用座標系統變數 #5021～#5024、#5041～#5044 與 #5083。
- FANUC 0M 設定可選標準 82 個或追加至 600 個共用變數、Offset Memory A/B 與 32/64/99/200/400 組刀補；程式可用 `#變數=算式` 寫入共用變數、刀補及 G54～G59，唯讀位置變數會報錯。
- 支援 `G10 L2 P1～P6` 依程式順序寫入 G54～G59，包含以 #2501/#2601 等既有原點值運算；可設定 `/` 選擇性跳段，G10 不會誤畫成移動刀路。
- 模擬步驟同步顯示相對座標與機械座標；工件原點的機械位置就是 G54（G55…），換算式為「相對座標＝機械座標−G54（G55…）−G52 局部偏移−刀長補正」，行程檢查以機械座標為準。
- 3D 模擬、毛胚、夾具及碰撞檢查共用唯一固定的機械座標原點 X0/Y0/Z0/W0；G54～G59 工件原點再由此固定原點偏移，模擬不使用第二組可輸入的機械起點。
- 以通用可調機台檢查行程、快移入料、刀具與方塊夾具風險，並以刀路掃掠提供近似材料去除預覽。
- 缺少 M98/G65 子程式或未知巨集時會略過並警告，分析結果標示不完整。
- 本工具不是控制器模擬器，也不能取代實機單節、乾跑與專業數位分身驗證。
