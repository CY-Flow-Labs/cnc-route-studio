# CNC Route Studio

[![CI](https://github.com/CY-Flow-Labs/cnc-route-studio/actions/workflows/ci.yml/badge.svg)](https://github.com/CY-Flow-Labs/cnc-route-studio/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

繁體中文、離線優先的 Fanuc 類 3+1 軸 CNC 路線模擬與程式預檢工具。目前版本為 **v1.7.8**。

它可在瀏覽器中同時載入 A／B 兩份 NC 程式，解析常見 G-code、顯示雙色 3D 刀路、比較差異，並在實機執行前協助發現行程、快移入料、刀具與夾具等潛在風險。

> 本公開版只包含虛構示範程式，不包含實際生產用 NC 程式、機台資料、客戶資料或歷史開發備份。

## 主要功能

- A／B 程式編輯、檔案匯入、下載及差異統計。
- 雙色 3D 刀路、逐步模擬、相對座標與機械座標顯示。
- 文字搜尋與命中項目巡覽。
- 8000／9000 系列巨集索引、G65 呼叫與 M98 子程式解析。
- 刀庫、口袋映射、刀號使用統計及主軸／待命刀追蹤。
- 可設定 G54～G59 工件原點、G43 H 刀長補正、自訂變數、毛胚及夾具。
- 行程、快移入料、刀具與方塊夾具風險檢查。
- 近似材料去除預覽與分析結果匯出。
- 可切換 `/` 選擇性跳段；關閉時執行斜線單節，開啟時略過。

## 系統需求

- Node.js 20.19 以上或 22.12 以上
- npm
- 支援 WebGL 的現代瀏覽器
- Windows 使用者可選用附帶的 PowerShell 一鍵啟動腳本

## 安裝與啟動

```bash
git clone https://github.com/CY-Flow-Labs/cnc-route-studio.git
cd cnc-route-studio
npm install
npm run dev
```

終端機會顯示本機網址，通常是 `http://localhost:5173`。所有解析與模擬均在本機瀏覽器內執行。

### Windows 桌面捷徑

在 PowerShell 執行：

```powershell
.\建立桌面捷徑.ps1
```

桌面會建立「CNC 雙程式路線模擬器」捷徑。之後點擊捷徑即可在背景啟動本機伺服器並開啟瀏覽器；若伺服器已啟動，只會開啟網頁。

## 基本使用流程

1. 開啟網頁後，在程式 A 或程式 B 區域匯入 `.nc`／文字格式的 CNC 程式，也可直接貼上內容。
2. 從程式索引選擇要模擬的主程式。
3. 依實際機台填入行程、G54～G59、刀長補正、刀具、毛胚與夾具資料。
4. 點選解析或模擬，查看 3D 刀路、診斷訊息、加工距離及估算時間。
5. 使用逐步控制確認換刀、座標系統、快移、切削與固定循環的執行順序。
6. 同時載入 A／B 程式時，可查看差異統計與重疊刀路。
7. 發現警告或不完整解析時，先修正程式或補齊機台參數，再進行實機單節與乾跑驗證。

## 支援範圍

- 常用 `G0/G1/G2/G3`、`G17/G18/G19`、`G20/G21`、`G54–G59`、`G80`、`G81–G84`、`G90/G91`。
- `X/Y/Z/W` 軸與基本 Fanuc 變數算式。
- `G10 L2 P1–P6` 依程式順序寫入 G54～G59。
- FANUC 0M 常用座標系統變數 `#5021–#5024`、`#5041–#5044` 與 `#5083`。
- 可選標準 82 個或追加至 600 個共用變數、Offset Memory A/B，以及 32／64／99／200／400 組刀補。
- 缺少 M98／G65 子程式或未知巨集時會略過並顯示警告，分析結果會標示為不完整。
- 其他固定循環在缺少必要機台資料時會回報未展開，不會產生推測刀路。

## 座標與安全說明

3D 模擬、毛胚、夾具與碰撞檢查共用固定的機械座標原點 `X0/Y0/Z0/W0`，G54～G59 再由此偏移。相對座標換算為：

```text
相對座標 = 機械座標 - 工件原點 - 刀長補正
```

本工具提供教學、視覺化與程式預檢，不是完整 CNC 控制器或經認證的數位分身。模擬結果不能取代實機單節、空跑、限速、刀具確認與合格人員的安全檢查。
